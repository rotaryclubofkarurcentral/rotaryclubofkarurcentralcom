# Rotary Club of Karur Central

This repository now uses VitePress as the main site. The site content lives under the `docs/` folder.

Local commands:

```
npm install
npm run dev       # starts VitePress dev server (docs)
npm run build     # builds static site into docs/.vitepress/dist
npm run start     # preview the built site
```

Site config: `docs/.vitepress/config.js`.
